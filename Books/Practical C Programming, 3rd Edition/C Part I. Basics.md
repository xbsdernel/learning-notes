Computers are designed to handle and process large amounts of information quickly and efficiently

C is a programming language that allows a software engineer to efficiently communicate with a computer.

C is used for a wide variety of programs including firmware for micro-controllers, operating systems, applications, and graphics programming.


C was designed with one goal in mind: writing operating systems.


Computer programs consist of two main parts: data and instructions.


The data in a computer is stored as a series of bytes.

C will handle the details of imposing that organization on the computer's memory.



`Struct` allow the programmer to arrange the data to suit his needs no matter how simple or complex that data is.


Source file containing source code. This file is transformed by the compiler into an object file. Next, a program called the linker takes the object file, combines it with predefined routines from a standard library, and produces an executable program.
